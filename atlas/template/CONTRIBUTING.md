# Contributing

## Before you write

1. Read `docs/guides/writing-here.md`.
2. Open a workstream: `atlas work new <slug> --owner <you>`.
3. Write the brief first. A draft without a brief is a guess.

## Before you open a pull request

```bash
atlas lint --changed --strict
atlas check
```

## What review means

Naming someone as a reviewer asserts that they read the document. Publication
needs an approver named in `authority.yaml`, and the author is never the sole
approver.
