# Agent guide

This is the canonical instruction file for AI agents working in this repository.
Vendor-specific files, if any, point here.

## What this repository is

Editorial content governed by the Atlas standard `editorial/1.0`. The standards
themselves live in the Atlas repository; this one follows them.

## Rules

- Every document declares `title`, `kind`, `owner`, `status`, and `updated` in
  front matter.
- Terminology comes from `library/lexicon/terms.yaml`. Do not invent a second
  spelling for anything.
- Record status in the task table of the workstream, and nowhere else.
- Never edit `work/README.md` or `work/index.yaml`; they are generated by
  `atlas work sync`.
- Propose a plan before deleting, rewriting, or retiring anything.

## Commands

```bash
atlas check                  # repository against the standard
atlas lint --changed         # prose you touched
atlas work sync              # regenerate the dashboard after editing tasks
```
