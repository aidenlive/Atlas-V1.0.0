# templates

Skeletons for the kinds of document we write most. Copy one, keep the front
matter, and replace the prose.

| File | Kind |
|---|---|
| [`guide.md`](guide.md) | A guide: prerequisites, numbered steps, verification |
| [`decision.md`](decision.md) | A decision record: context, decision, consequences |
| [`announcement.md`](announcement.md) | An announcement: what changed, who is affected, what to do |
