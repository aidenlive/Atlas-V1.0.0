# Security Policy

This repository contains specifications and validation tooling; it ships no
runtime service. Relevant reports:

- Flaws in the tooling (`scripts/`, `tests/`) that could damage a consumer's
  repository or CI.
- Errors in the standards that would *systematically* weaken the security
  posture of adopting projects (e.g., a checklist item that legitimizes an
  unsafe practice).

**Report privately** via GitHub Security Advisories on this repository
(preferred) or to the owner listed in `project.yaml`. Do not open public
issues for vulnerabilities. Acknowledgement target: 5 business days
(`support: best-effort`).
