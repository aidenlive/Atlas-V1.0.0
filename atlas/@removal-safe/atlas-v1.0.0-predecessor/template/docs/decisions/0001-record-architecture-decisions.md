# 0001: Record architecture decisions

Date: {{DATE}} · Status: Accepted

## Context
Significant decisions need a durable "why" that survives team turnover.

## Decision
We record architecture decisions as ADRs in this directory: numbered, dated,
immutable once accepted, superseded rather than edited.

## Consequences
"Why is it like this?" has a findable answer forever; superseded designs stay
visible without haunting the working tree.
