## 2. Map
```
src/     ← all shipped code
tests/   ← mirrors src/ topology
docs/    ← architecture, decisions (ADRs), guides
work/    ← every initiative as a numbered workstream; README.md and index.yaml
           are GENERATED by atlas work. Read them, never edit them
assets/  ← banner, screenshots, diagrams (PRESENTATION P-02; SVG preferred)
```

## 3. Commands
```bash
# build:
# test:
# lint:
atlas work new|sync|validate|archive   # work management
```
Keep these copy-paste true or the repo fails ID-07.

## 4. Conventions
Conventional Commits; branches `type/short-description`; SemVer tags `vX.Y.Z`.

## 5. Constraints
- Do not edit generated files (list them here).
- Do not commit secrets; config via environment.
- Accepted ADRs in docs/decisions/ are immutable.
- Never hand-edit work/README.md or work/index.yaml; edit the workstream
  Markdown, then run `atlas work sync`.
- Never mark a workstream `done` without evidence for every acceptance
  criterion.

## 6. Definition of Done
Tests pass, lint clean, CHANGELOG entry added, docs updated.
