# Typefaces

Font families and the licenses that permit them. The license ships in the same
directory as the files: no license, no typeface. Web formats are generated from
the source by a script, never hand-converted, and every family declares the
fallback stack that applies before it loads and if it never does (L-T1–L-T3).
