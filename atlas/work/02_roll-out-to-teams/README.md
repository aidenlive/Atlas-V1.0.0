# Roll the standard out to teams

`02_roll-out-to-teams` · owner role:standards-maintainer · opened 2026-08-08

One editorial initiative. The five sections below are the same in every
workstream, so anyone joining finds the brief in the same place.

| Section | Holds |
|---|---|
| [`01_brief/`](01_brief/brief.md) | What we are writing, for whom, and why |
| [`02_tasks/`](02_tasks/tasks.md) | The task table — the only place status lives |
| [`03_drafts/`](03_drafts/README.md) | Drafts, or pointers to where they live |
| [`04_review/`](04_review/review.md) | Reviewers, comments, and sign-off |
| [`05_publication/`](05_publication/publication.md) | Where it went, and what happens next |

Facts about this workstream — status, owner, kind, audience, dates — live in
`workstream.yaml`. Progress is counted from the task table by `atlas work sync`.
