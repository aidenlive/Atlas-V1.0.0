# 3. Generated views, never hand-maintained ones

Date: 2026-08-08

## Status

Accepted.

## Context

Every index, dashboard, and badge in the predecessor started accurate and drifted.
Not through carelessness: they change on a different trigger from the thing they
describe, so they are always updated one edit late, and eventually not at all.

## Decision

Any view assembled from something else is generated by a script and marked as
generated. Four exist: the CLI reference from the argument parser, the prompt
index from the prompt files, the work dashboard and index from the task tables,
and the badges from `project.yaml`.

A gate checks that the generated file matches what regenerating it would produce.

## Consequences

A badge cannot claim a maturity the manifest no longer says. A workstream cannot
report itself further along than its own task list. The reference cannot
describe a flag the tool lacks.

The cost is that hand-editing a generated file is now a wasted edit — which is
why each one carries a comment at the top saying so.
